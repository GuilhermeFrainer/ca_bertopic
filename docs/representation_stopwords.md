# Representation Stop Words Removal

## Overview & Rationale

During topic modeling experiments, topic representations generated by BERTopic's c-TF-IDF phase can sometimes be populated by uninformative English stop words (e.g., "the", "and", "to", "of"). 

Rather than stripping stop words from original document texts during embedding generation (which degrades contextual semantic representations built by transformer-based language models), BERTopic supports filtering stop words at the **representation extraction layer**.

Using `sklearn.feature_extraction.text.CountVectorizer(stop_words="english")` as the `vectorizer_model` in BERTopic filters out stop words strictly during the calculation of class-based TF-IDF topic word scores.

---

## Architectural Benefits

1. **Preserves Contextual Embeddings**: The underlying sentence and document embeddings remain trained on natural, unmanipulated text with full syntactic structure.
2. **Clean Topic Representations**: Extracted topic keywords and topic summaries are clean, domain-informative, and free of high-frequency stop word noise.
3. **Decoupled Architecture**: Representation filtering is fully isolated from document preprocessing, metadata scaling, dimensionality reduction, and clustering algorithms.

---

## Usage & Configuration

### 1. Command-Line Interface (CLI)

Both single-experiment and hyperparameter optimization scripts support the `--remove-rep-stopwords` flag:

```bash
# Standard experiment
uv run python scripts/experiments/run_experiment.py --exp yelp_standard_baseline --remove-rep-stopwords

# Hyperparameter optimization
uv run python scripts/experiments/run_optimizer.py --exp yelp/yelp_standard_baseline --remove-rep-stopwords
```

> **Note**: The `--remove-rep-stopwords` flag explicitly specifies that stop words are removed only from topic representations (c-TF-IDF keywords) and does **not** alter input texts or pre-computed embeddings.

### 2. Experiment YAML Configuration

Alternatively, stop word removal can be declared directly inside an experiment YAML configuration under `bertopic.params`:

```yaml
models:
  - id: "baseline"
    is_baseline: true
    dimensionality_reduction:
      type: "umap"
    clustering:
      type: "hdbscan"
    bertopic:
      params:
        top_n_words: 50
        remove_rep_stopwords: true
```

### 3. SLURM Automated Queue

The SLURM queue orchestrator script [`scripts/pipelines/slurm/queue_exp.sh`](../scripts/pipelines/slurm/queue_exp.sh) automatically includes `--remove-rep-stopwords` in all dispatched optimization jobs.
